贰 从进来到开张

四步开张，剩下的交给街坊

第一次进集市只问一件事：性别。名字沿用论坛用户名，不另注册一套。 之后每一步都有明确去处——挑一块地、选一间样式、确认租赁，货就能上架。

  1. 开市

    村长把地图画到位，地皮满 64 格、物件至少 1 个，保存那一刻集市自动开张；没达标的日子，玩家只看到一扇贴了酒楼图样的门。

  2. 认个门牌

    首次进入只选男士 / 女士两尊形象，头像与站点用户名直接同步，金币从 0 起步。

  3. 圈地起铺

    村长在空地上拖框选 2~12 格，写明摊位名称、用途标签与日租金（预设 10 / 20 / 30 / 50）。模板自带六块街面铺位：北街一二三号（杂货、茶食、布匹）、南街一二三号（书画、早点、酒肆）。

  4. 上货成交

    租下铺位后从 13 种样式里挑一间，货摆上货架；别人点开你的摊就能拍下，卡片以商品形式在帖子里流转。

叁 积分 ⇄ 金币 · 交子铺

论坛的积分，能换成集市上的铜钱

两套货币打通，但口子攥在后台手里：基准汇率、买卖价差、每日波动、快捷兑换额度，全是一行行整数。 存钱生息、青苗借贷，则归交子铺的掌柜管。

兑换通道
交子铺 · 柜台上的三张告示

  • 基准 1 : 10

    1 金币兑 10 积分起步，可调 0.01~100000；后台备了 1:1 / 1:10 / 1:50 / 1:100 四片预设。

  • 买卖价差 4%

    玩家买入价恒不低于卖出价的 104%，堵住来回套利的缝；每日还能开 ±5% 的行情波动。

  • 快捷兑换 200 / 日

    右上角的「兑换」按钮走小额通道，买卖合并计额度；想大额，去信用社找掌柜。

  • 同事务提交

    台账、积分、金币在一个事务里落库，固定锁序 + 32 位幂等键，重复请求只认一次。

铁匠铺 · 熔炉环

黑市寄卖

道具上架即锁定，单笔 1~99 件、单价最高一亿金币；成交走行锁，手慢了提示「商品已被买走」。村长可整市歇业，在售商品原样保留。

村委会签到

每日一次，找村委会主事领今日福利：默认一册残破卷轴加两束干药材，最多配 12 条。领取瞬间道具图标会从建筑飞进右上角背包。

道具与品阶

拾 装一台集市

三步装好，明早开市

插件是一个文件夹，里头一份 plugin.php 加一目录素材。 下载、放进插件目录、同步插件，剩下的都在后台点。

  1. 下载插件包

    从 GitHub Releases 取 jishi.zip，或到仓库页浏览源码。包内已含 122 项素材与两段音乐。

  2. 放进插件目录

    解压得到 pixel_market/，整目录放进站点的插件目录；想连散场清理一起装，就再放一个 pixel_market_cleaner/。

  3. 同步插件

    在站点后台同步一次，22 张 plugin_pixel_market_ 表自动建好，侧栏与搜索框右侧同时出现「集市」入口。

  4. 画地图，开市

    进后台「集市设置」载入模板或自定义地图——地皮满 64 格、物件至少 1 个，保存那一刻集市自动开张。

拾壹 常见问题

开张前先问清楚

装法、数据、性能、素材替换——站长最关心的四件事，先答在这儿。

集市和论坛是什么关系？会另开一套账号吗？

不会。集市是内嵌在论坛里的一个插件页，入口有三处：侧栏「快捷功能」、搜索框右侧的「集市」按钮、管理员菜单里的「集市管理」。玩家身份直接沿用站点用户名，首次进入只补一个性别选项。

站点管理员默认即村长，不需要再在集市里申请一次权限。

积分和金币怎么换？会不会把论坛的积分体系冲垮？

兑换走固定通道：基准 1 金币 = 10 积分，玩家买入价至少比卖出价高 4%，快捷兑换每天 200 金币封顶（设为 0 就干脆隐藏按钮），信用社柜台才不受这个额度限制。行情还可以按 ±5% 每日波动。

交子铺的条款同样写在后台：定期存帖默认 7 天 0.5%、30 天 0.8%，最低存 100 金币、最多同时持有 3 张存帖，提前支取按 0.1% 活期算。青苗贷日息 1.5%，额度随在租铺位的等级水涨船高，逾期每日 3% 罚息、宽限 3 天。

地图能画多大？会不会卡？

边长 8 到 200 格，一格 64 设计像素；地图物件硬上限 2000，后台默认收到 800。

地面按 8×8 格区块做离屏缓存，改动才重绘；渲染只处理视口内的格子；碰撞是物件级的矩形与圆形盒，不是整图检测。寻路用八向 A* 并防切角，游荡 NPC 错峰计算路径，每帧只放一个。

不喜欢某间铺面的样子，能换图吗？

能。插件里维护着一份 122 项的素材白名单（键 → 分类 / 文件 / 类型），站点在数据目录的同名覆盖层里放一张同名 PNG 就能替换，不用动代码；后台「素材管理」会列出每一项的就位状态与大小，也支持打包上传。

不想要的样式可以整类停用——比如默认停用的近代元素理发摊。

买过的卡片内容，店主事后改了买家还看得到吗？

看得到当时那一版。购买瞬间会把标题、徽章与正文各存一份快照，与店主后续修改解耦；限购计数连软删记录一起算，防止反复上架绕额度。

未购买的路径上，查询语句里根本不取正文字段——这是注释里写明的防泄露红线。

支持哪些数据库？表名会不会撞？

SQLite、MySQL、PostgreSQL 三种驱动共用一套读写；22 张表全部以 plugin_pixel_market_ 打头，函数、常量、CSS、JS 也统一带 pixel_market_ 前缀。

兑换与购买这类涉及钱的操作在同一事务里提交，固定锁序，MySQL / PostgreSQL 用 FOR UPDATE，SQLite 靠 BEGIN IMMEDIATE。

不想要了，怎么干净卸载？

删插件文件夹、同步插件之后，再装一次配套的 集市残留清理：它在后台列出遗留的数据表、计划任务、素材覆盖目录、备份文件和发给用户的通知，一键清扫，顺带修正未读计数。

清理插件只认明确属于集市的对象；它自己的表以 plugin_pixel_market_cleaner_ 打头，扫表时会跳过。
